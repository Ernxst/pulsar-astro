# Components

Pulsar ships with some built-in components that you can use to enhance your documentation site.

- [Accordion](/docs/en/guides/components/accordion)
- [Select](/docs/en/guides/components/select)
- [Theme Switcher](/docs/en/guides/components/theme-switcher)

The Theme Switcher component is included in your pages by default - you can disable it in your Pulsar configuration and manually place them where you like.
